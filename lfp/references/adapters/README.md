# Platform adapters — LFP

LFP is tool-agnostic. Adapters map research dispatch to your host.

| Adapter | Host | Research dispatch |
|---|---|---|
| [cursor.md](cursor.md) | Cursor Agent | Task subagents, parallel |
| [claude-code.md](claude-code.md) | Claude Code | Subagents or parallel sessions |
| [generic.md](generic.md) | Any agent | Sequential paste prompts |
