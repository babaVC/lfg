# Option matrix — presentation format

Present after Phase 1 integration, before first interview (Phase 2).

## Template

| Route | Summary | Pros | Cons | Effort | Risk | Recommended? |
|-------|---------|------|------|--------|------|--------------|
| **A** | … | … | … | S/M/L | Low/Med/High | Yes / No |
| **B** | … | … | … | … | … | … |
| **Hybrid** | … | … | … | … | … | if applicable |

## Single-route case

When research finds only one viable path, **do not invent option B**. Present:

| Route | Summary | Pros | Cons | Effort | Risk |
|-------|---------|------|------|--------|------|
| **A (only viable)** | … | … | … | … | … |

**Alternatives considered:** {list what was evaluated and rejected, or "none worth pursuing" with one-line why}.

## Conductor notes

- **Recommended?** — conductor's honest pick, not a rubber stamp on the user's initial idea
- **Effort** — rough: S (~1 session), M (multi-phase), L (multi-gate / security-critical)
- **Risk** — what breaks if this route is wrong

## First interview (AskQuestion)

Batch 2–4 questions:

1. Which route? (include hybrid if real)
2. Explicit rejects — what are we NOT doing?
3. Constraints from brief that override research?
4. (Optional) If hybrid — which parts from which route?

Lock primary decision in plan §2 before Phase 3 draft.
