## "LFP" / "Let's fucking plan"

Structured planning before execution. **Opposite of winging it.** Plan must be LOCKED before `/lfg`.

1. Read `skills/lfp/SKILL.md` (or `/lfp` in chat) — symlink to `~/Cursor porjects/lfg/lfp/`
2. **Conductor** — parent orchestrates: goal lock → parallel research subagents → option interview → draft plan (CreatePlan / harness plan file) → scope interview → LOCKED file + LFG handover
3. Paste prompt from `lfp/references/lfp-prompt.md` with brief attached
4. Deliverable: plan path under `docs/plans/` or `{project}/plans/` + paste-ready `/lfg` invocation
5. Stop when LOCKED + §12 LFG Handover complete — not when draft "looks good"

Not for quick fixes (≤15 files), greenfield product kickoff (new-product), or research-only.

**Plan first (`/lfp`), ship second (`/lfg`).**
